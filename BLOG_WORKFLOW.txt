PERSONAL WEBSITE — KREIRANJE NOVOG BLOGA
=========================================


1. UĐI U PROJEKAT
-----------------

cd ~/Projects/personal-website


2. UBACI SLIKU
--------------

Ako je slika u ~/Pictures:

cp ~/Pictures/ime-slike.jpg assets/images/ime-slike.jpg

Provjera:

ls assets/images


3. KREIRAJ NOVI MARKDOWN POST
-----------------------------

Ime fajla:
- bez razmaka
- bez č, ć, š, ž, đ
- koristi crtice

Primjer:

nvim blog/md/moj-novi-blog.md


4. TEMPLATE ZA NOVI BLOG
------------------------

KOPIRAJ OVO U .md FAJL:


---
title: Ovdje ide naslov bloga
description: Ovdje ide kratak opis bloga koji će se prikazati na početnoj stranici.
image: assets/images/ime-slike.jpg
alt: Kratak opis slike
---

Ovdje počinje tekst bloga.

Prvi paragraf mogu normalno napisati ovdje.

## Prvi podnaslov

Ovdje ide tekst prve sekcije.

Mogu naglasiti **bitne riječi** koristeći dvije zvjezdice.

## Drugi podnaslov

Ovdje ide još teksta.

Mogu koristiti listu:

- prva stvar
- druga stvar
- treća stvar

## Outro

Završni dio bloga.


5. MARKDOWN KOJI TREBAM ZNATI
-----------------------------

Glavni podnaslov:

## Naslov

Manji podnaslov:

### Naslov

Bold:

**bitna riječ**

Italic:

*tekst*

Lista:

- stavka
- stavka
- stavka

Kod:

`neka-komanda`

Link:

[GitHub](https://github.com/)


6. SAČUVAJ U NVIM
-----------------

:wq


7. GENERIŠI HTML
----------------

.venv/bin/python build_blog.py

Generator automatski:

- pravi HTML u blog/posts/
- dodaje blog na index.html
- dodaje datum
- dodaje vrijeme
- dodaje slug
- računa vrijeme čitanja


8. PREGLEDAJ BLOG
-----------------

Pokreni server:

python -m http.server 8000

Otvori homepage:

xdg-open http://localhost:8000

Ili direktno određeni blog:

xdg-open http://localhost:8000/blog/posts/ime-posta.html

Ako CSS izgleda staro:

Ctrl + Shift + R

Ugasi server:

Ctrl + C


9. AKO ŽELIM EDITOVATI POST
---------------------------

VAŽNO:

NE EDITUJ:

blog/posts/ime-posta.html

To je generisani HTML.


EDITUJ:

blog/md/ime-posta.md


Primjer:

nvim blog/md/moj-novi-blog.md

Nakon izmjene OBAVEZNO:

.venv/bin/python build_blog.py


10. OBJAVI NA GITHUB
--------------------

Provjeri promjene:

git status

Dodaj sve:

git add -A

Commit za novi blog:

git commit -m "Add new blog post"

Commit za editovan blog:

git commit -m "Update blog post"

Push:

git push

Provjera:

git status


11. CIJELI WORKFLOW UKRATKO
---------------------------

cd ~/Projects/personal-website

nvim blog/md/ime-posta.md

.venv/bin/python build_blog.py

python -m http.server 8000

git status
git add -A
git commit -m "Add new blog post"
git push

----------------------

==================

blog/md/

blog/posts/

Proces:

PIŠI → BUILD → PROVJERI → COMMIT → PUSH
